# 코드 구조

## UI

| 영역 | 핵심 파일 | 역할 |
| --- | --- | --- |
| 진입점 | `src/ui/src/main/java/com/amazon/sample/ui/UiApplication.java` | Spring Boot WebFlux 시작 |
| endpoint 설정 | `config/EndpointProperties.java`, `config/StoreServices.java` | `retail.ui.endpoints.*` 바인딩, Kiota/mock 서비스 구성 |
| Web 계층 | `web/CatalogController.java`, `CartController.java`, `CheckoutController.java`, `AuthenticationController.java`, `OrderManagementController.java` | HTML 경로, 회원가입, 세션 로그인과 폼 처리 |
| 보안 설정 | `config/SecurityConfig.java` | `/demo/orders` 인증 요구, WebSession 보안 컨텍스트, Orders API 위임 로그인 |
| 통합 계층 | `services/{catalog,carts,checkout,orders}/` | 생성된 HTTP client 호출 |
| 생성 client | `client/{catalog,cart,checkout,orders}/` | Kiota request builder와 API 모델 |
| View | `src/main/resources/templates/` | Thymeleaf 페이지·프래그먼트, `login.html`, `register.html` |
| 테스트 | `src/test/java/` | UI 설정, 유틸리티, Orders service/controller 테스트 |

`StoreServices`가 구성 루트다. endpoint가 있으면 Kiota client, 없으면 mock을 선택한다. 단 Orders는 `OrdersService(null)`로 구성되어 목록 조회가 실패한다.

## Catalog

| 영역 | 핵심 파일 | 역할 |
| --- | --- | --- |
| 진입점·router | `src/catalog/main.go` | 환경변수, repository, Gin route, health, metrics, tracing 초기화 |
| Handler | `src/catalog/controller/controller.go` | 상품·태그·크기·검색·reindex 처리 |
| Domain API | `src/catalog/api/catalog.go` | 상품/태그 유스케이스와 검색 조정 |
| 영속화 | `src/catalog/repository/{repository,data,opensearch}.go` | 메모리 JSON, MySQL, OpenSearch 구현 |
| 데이터·모델 | `repository/products.json`, `model/` | 시드 데이터와 응답 모델 |
| 테스트 | `src/catalog/test/` | Go controller/main/chaos 테스트 |

## Checkout

| 영역 | 핵심 파일 | 역할 |
| --- | --- | --- |

| 테스트 | `test/` | Jest 통합 설정; 기본 `test` script는 `exit 0` |

## Orders

| 영역 | 핵심 파일 | 역할 |
| --- | --- | --- |
| 진입점 | `src/orders/src/main/java/com/amazon/sample/orders/OrdersApplication.java` | Spring Boot와 messaging listener 시작 |
| HTTP API | `web/OrderController.java`, `web/UserController.java` | `POST /orders`, `GET /orders?customerEmail=`, `POST /users`, `POST /auth/login` |
| 도메인·영속화 | `services/{Order,User}Service.java`, `repositories/{Order,User}Repository.java`, `entities/` | Spring Data JDBC로 주문 aggregate와 사용자 저장·조회 |
| API 매핑 | `web/payload/{OrderMapper,OrderItemMapper}.java` | MapStruct API/entity 변환 |
| DB 구성 | `config/{DataSource,Persistence}Config.java`, `db/migration/V1__Initial.sql`, `V2__Users.sql` | provider 선택, 주문/사용자 ID, 스키마 |
| 메시징 | `messaging/OrdersEventHandler.java`, `messaging/{inmemory,rabbitmq,sqs}/` | 저장 후 order-created 이벤트 발행 |
| 테스트 | `src/test/java/` | application, metrics, chaos, PostgreSQL Testcontainers 테스트 |

## `ui-backup`

`src/ui-backup/`은 UI와 유사한 완전한 소스 스냅샷이다. 이 디렉터리 밖에서 참조를 찾지 못했으며, 활성 서비스로 간주하지 않았다. 삭제·빌드·배포 전에 소유자에게 용도를 확인해야 한다.
